跨网段摄像头探测（进阶教程）

适用：摄像头和 NAS 不在同一个网段 时，TS Safe 控制台显示摄像头「离线」的解决办法。 如果你家所有设备都在同一个网段（例如都是 192.168.8.x），你不需要做任何事，直接忽略本文。

为什么控制台显示「离线」？
这不是摄像头坏了，也不是软件问题，而是家庭网络拓扑决定的：摄像头接在运营商光猫下（192.168.1.x）， NAS 接在主路由下（192.168.8.x）。NAS 发往摄像头的包能到主路由，但摄像头回包时，光猫不认识 NAS 所在的 192.168.8.x 网段，包回不来，于是 NAS 探不到摄像头，控制台显示「离线」。

TS Safe 已做「尽力探测」：先 ping，不通再试常见端口（80/443/554/8080/8000/37777/34567）。 网络能通就显示在线；通不了就诚实显示离线，而不是假装在线或误报故障。

原理（一句话）

让主路由对「从 NAS 网段发往摄像头网段」的流量做一次 源地址转换（SNAT / MASQUERADE）。 摄像头回包先回到主路由（同 192.168.1.x 段，光猫认识），再由主路由转给 NAS。 光猫全程无感知，也不需要你有光猫的管理权限。 NAS 本身不用接任何多余的线。

操作步骤（以华硕路由器为例）

以下以 华硕 RT-BE88U（固件 3.0.0.6.x，原厂 AsusWrt） 为例，其它品牌思路完全一致。

1. 开启 SSH 与脚本持久化

  1. 登录路由器管理页（通常 http://192.168.8.1）。
  2. 进入 系统管理 → 系统设置。
  3. 设置：
    • 启用 SSH：是（连接方式选 LAN only 即可）
    • 启用 JFFS 自定义脚本和配置：是
  4. 点击 应用本页面设置。

2. 登录路由器并先测试规则

ssh admin@192.168.8.1     # 密码是你路由器的管理密码

# 先手动加一条规则测试（确认有效再固化，免得无效时难排查）：
iptables -t nat -A POSTROUTING -s 192.168.8.0/24 -d 192.168.1.0/24 -o wan0 -j MASQUERADE
参数含义示例
-s 192.168.8.0/24NAS / 电脑所在网段你家主路由 LAN 段
-d 192.168.1.0/24摄像头所在网段你家光猫段
-o wan0华硕 WAN 接口名若不同，用 ip addr 看拿到光猫段 IP 的接口

3. 在 NAS 上验证

ping 192.168.1.240     # 换成你摄像头的真实 IP

能通 → 跨网段探测已打通。回到 TS Safe 控制台刷新或重新检测该摄像头，就会显示「在线」。

4. 固化规则（重启不丢）

cat > /jffs/scripts/nat-start <<'EOF'
#!/bin/sh
iptables -t nat -A POSTROUTING -s 192.168.8.0/24 -d 192.168.1.0/24 -o wan0 -j MASQUERADE
EOF
chmod +x /jffs/scripts/nat-start

路由器每次开机 / 重建 NAT 会自动执行该脚本，规则永久保留。重启后再 ping 一次确认即可。

如果第 3 步 ping 不通，按顺序排查

  1. 防火墙拦截 LAN→Intranet：路由器 防火墙 → 一般设置 若有「阻止 LAN 访问 WAN 上的私有网络」之类开关，先关掉；或加一条允许转发： 
    iptables -I FORWARD -s 192.168.8.0/24 -d 192.168.1.0/24 -j ACCEPT
  2. 确认主路由 WAN 在摄像头网段：路由器 网络地图 / 外部网络(WAN) 里 WAN IP 应为 192.168.1.x。 若不是（如光猫桥接 + 主路由 PPPoE 拨号），WAN 侧没有摄像头网段直连路由，需先调整上网方式。
  3. 新固件 nftables 兼容：3.0.0.6.x 底层是 nftables，极少数情况 iptables 规则不生效。 可把 wan0 换成实际接口（ip addr 查看），或改用 nft 命令。

其它品牌 / 不想动路由器怎么办

  • 其它智能路由（OpenWrt / 爱快 / 小米 / 华为企业级等）：思路一致，对该段流量加 SNAT / MASQUERADE 即可，仅命令与界面不同。
  • 不想动路由器：用一对 电力猫（电力线适配器） 把光猫 LAN 口延伸到 NAS 旁，给 NAS 接第二网口并配摄像头网段静态 IP（网关留空），NAS 与摄像头同二层，无需改路由器。
  • 摄像头可迁移：未来换可自管摄像头（海康 / TP-Link 普通款），接主路由下与 NAS 同网段，开箱即用。

小结

情形需要做什么
摄像头与 NAS 同网段什么都不用做，TS Safe 直接探测在线
摄像头在光猫独立网段默认显示离线属正常；进阶用户按本文在主路由加一条 SNAT 规则即可看到在线
完全不想碰路由器用电力猫延伸光猫 LAN 到 NAS 旁，或换可自管网段的摄像头
