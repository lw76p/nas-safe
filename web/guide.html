TS Safe 使用指南

全功能开源免费 · NAS / Windows 电脑 / Mac / Linux / 摄像头 / 路由器统一管控 · 本文档随镜像内置，离线可看

一、这是什么

TS Safe 是装在 NAS 上的数据安全总控台，主打「防勒索 + 快照 + 取回还原」，附带重复文件清理、磁盘清理、换机迁移、日报、AI 管家。设备数、AI 额度、迁移、知识库全部不设限、不收费。

  • NAS（本机）：装它的这台，功能全开，是总控台。
  • Windows 电脑：零安装接入，可远程执行 / 重启 / 关机。
  • Mac / Linux 电脑：装完整版 TS Safe 后主动报到，看完整指标。
  • 摄像头：只做在线检测（ping）。
  • 路由器 / 软路由：仅监控，显示在线 / 离线。

二、NAS 安装（一条命令装完）

★ 零依赖一条命令（NAS 上什么都不用准备，SSH 进去直接粘贴——自动下载脚本 → 拉镜像 → 装完）：

curl -fsSL https://cdn.jsdelivr.net/gh/lw76p/nas-safe@main/install_nas_safe.sh -o install.sh && sudo bash install.sh

脚本已在手时（离线安装 / 指定数据目录）：

sudo bash install_nas_safe.sh                      # 自动选最大的卷
sudo bash install_nas_safe.sh /share/我的目录       # 或自己指定数据目录

脚本会自动：找 docker → 选剩余空间最大的存储卷 → 拉镜像（不用提前 docker pull） → 起容器 → 健康检查 → 打印控制台地址。控制台已装好的机器也可在线获取脚本：

curl -fsSL http://<NAS的IP>:8848/api/downloads/install_nas_safe.sh -o install.sh

手动方式（想一步步来时用）：

docker run -d --name nassafe \
  --network host \
  -v /share/CE_CACHEDEV1_DATA/nassafe_state:/app/state \
  --restart unless-stopped \
  <镜像仓库地址>/nas-safe:latest

装完打开 http://<NAS的IP>:8848，首次进入会要求注册管理员账号。接入 Windows 电脑用的「一键开启脚本」，在控制台设备页有下载按钮，「添加电脑」弹窗里也可直接下载。

数据（账号 / 设备 / 快照记录 / 配置）全部落在挂载的 /app/state 目录，升级或换容器不丢。

三、接入 Windows 电脑（零安装）

  1. 在电脑浏览器打开 http://<NAS的IP>:8848/api/downloads/enable-winrm.ps1，下载「一键开启」脚本。
  2. 右键脚本 → 使用 PowerShell 运行 → UAC 点「是」。脚本做 5 件事：起 WinRM、放行防火墙、开 Basic 认证、解除 UAC 远程令牌降权、把当前账户加进远程管理组。
  3. NAS 控制台 → 设置 → ＋添加设备 → 添加电脑，填电脑 IP + 管理员账号密码。
⚠️ WinRM 基本认证只认本地账户。如果这台电脑用微软 / Azure AD 账户登录，请先建一个本地管理员账户（设置 → 账户 → 其他用户），用那个账户接入。

多台 Windows 电脑 = 每台各跑一次脚本。脚本只是打开 Windows 自带开关，不是装软件。

四、接入 Mac / Linux 电脑

不装任何脚本，直接装 TS Safe 完整版：控制台 → 点设备卡片 → 「⬇ 下载完整版安装包」→ 拷到目标机解压：

# Linux（systemd 开机自启，需 root；Python ≥ 3.10）
sudo bash install_service.sh

# macOS（launchd 开机自启，免 sudo）
bash install_service.sh

装完自动向总控台报到（60 秒心跳），控制台里即显示在线与完整指标。

五、AI 与知识库

  • AI 配置：设置 → AI 配置，填任意一家云端 AI 的 API Key（推荐 DeepSeek），或填本地 Ollama 地址。调用次数不限量。
  • 知识库：设置 → 知识库，上传 txt / md / pdf / docx 等文档，之后「问 AI」可勾选「结合知识库回答」。额度不限量。
  • 照片语义搜索：设置 → 照片搜索，建立索引后用自然语言找图。

六、常见问题

现象原因 / 处理
添加电脑后显示离线① 电脑没跑一键脚本；② 用了微软账户登录（见上方警告）；③ 防火墙拦了 5985 端口
路由器 / 摄像头显示离线仅监控设备按探活判定：确认 IP 正确、设备允许 ping / 管理端口开放
AI 回答失败设置 → AI 配置里填好 API Key 并启用；本地 Ollama 需先在本机跑起来
忘了管理员密码在 NAS 上执行 docker exec -it nassafe python3 server/reset_admin.py 用户名 新密码
快照在哪里由存储卷的快照能力决定（btrfs / zfs / VSS / APFS），控制台「快照」页可查看与取回
