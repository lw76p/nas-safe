## 一、核心判断

### 不能卖"功能"，要卖"安心"和"省事"

快照是系统白送的原料（飞牛、绿联、群晖都有），你收不了"快照钱"。用户愿意付费，是因为：

- **我不用管** —— 装完默认开启，不用研究系统面板
- **出事能救回来** —— 这是保险，不是工具

**定价锚点：数据值多少钱，而不是功能有多少个。**

### 一条残酷的行业现实

NAS 用户的付费心理很特殊：

| 群体 | 特征 |
|---|---|
| 群晖用户 | 被生态锁死，不得不付 |
| **飞牛/绿联用户** | **"我来就是为了省钱"，纯软件收费很难** |

**但他们有一条共同的心理缺口：一旦数据真出过事，或意识到可能出事，付费意愿立刻翻转。**

所以收费逻辑必须围绕**风险焦虑**设计，不是围绕功能列表。

### 收费重点（2026-10-01 拍板）：硬盘健康监控

**SMART 硬盘健康监控不是"往后放"的垫脚石，它就是收费的重点。** 三个理由：

1. **它是产品里唯一"事前"的功能。** 快照、回滚、取回全是"出事后救回来"；篡改告警是"出事的那一刻知道"。只有硬盘健康监控能在**灾难发生之前**告诉用户"你的盘正在走向死亡" —— 焦虑前置，付费动机最强。
2. **恐惧比悔恨更高频。** "我的硬盘快坏了"是每个 NAS 用户都会反复想起的事（盘用了三五年、异响、变慢），而"我中了勒索"是低频想象。**用高频焦虑养付费，比用低频恐惧可靠。**
3. **它是天然的持续服务。** 每日自动采集 + 趋势外推 + 微信推送预警，有真实的持续成本（推送中转、云端链路）—— 这让"免费当前状态 / 付费趋势预测与预警"的分界线干净、诚实、好讲。

**免费/付费分界：免费版给"现在的健康状态"（只读展示），付费版给"还能活多久"（趋势预测 + 寿命评分 + 微信预警推送）。**

## 二、定价结构（买断制）

| 版本 | 价格 | 包含内容 |
|---|---|---|
| **免费版** | **¥0** | 核心引擎 + 时间轴 UI + 单文件取回 + 一键回滚 + 空间清理 + 基础体检 + 硬盘健康**当前状态**展示（**全功能不限量**） |
| **进阶版** | **¥69 买断** | **硬盘寿命趋势预测 + 微信预警推送（收费重点）** + v1.x 全部功能 + v1.x 所有小版本更新 |
| **进阶版 Pro** | **¥99 买断** ← **主推** | 同上 + 未来所有大版本免费升级 |
| **企业版** | 按台议价 | 集中管理、审计日志、权限分级、双人复核、SLA |
| **代部署服务** | **¥100-300/次** | 远程帮装 + 配置策略（软件免费，服务收费） |

### 为什么免费版必须"够用"

很多独立开发者栽在这里：免费版阉割太狠，用户下载完发现"看个时间轴都要付费"，直接卸载，口碑还烂了。

**免费版要给到"能自救"的程度：**

- 时间轴可视化
- 手动拍快照
- 单文件取回
- 整卷回滚
- 基础容量检测

**两个理由：**

1. **免费版是最好的广告。** 用户真靠它救回一次数据，他会主动发帖、发群、发视频 —— 这是买不到的口碑
2. **收费点放在"用户自己做不到的事"上**

### 付费边界怎么划（核心）

| 收费点 | 为什么用户愿意付 |
|---|---|
| **硬盘健康监控**（SMART 趋势预测 + 寿命预警 + 微信推送）← **收费重点** | 唯一能在"出事之前"开口的功能。硬盘一坏数据全没 —— 这比勒索软件更高频、更具体。每天自动采集、趋势外推、坏了提前微信通知，用户买的是"提前知道" |
| **自动快照策略**（每小时/每天/智能） | 手动拍快照，人一定会忘。勒索软件不怕你忘了吗？ |
| **快照锁定 + 独立权限** | 这是产品存在的理由。系统自带的锁，用户不知道锁没锁住 |
| **篡改检测告警** | 快照被删的那一刻就通知你 —— "安心"的具象化 |
| **异地不可变副本** | 家里 NAS 被偷/烧了也能救。最硬的付费理由 |
| **多设备统一看板** | 有 2 台以上 NAS 的人，本身就是付费意愿最强的群体 |
| **AI 功能**（人话解读、语义搜索） | 有调用成本，必须放付费版 |

**关键分界线：**

- 免费版解决 **"我今天不小心删了文件"** → 日常小确幸 → 用户感谢你
- 付费版解决 **"我中了勒索 / 家里出事了"** → 生死攸关 → 用户掏钱
- **硬盘健康监控横跨两者：免费版告诉你"现在好不好"，付费版告诉你"还能活多久、变坏了立刻微信通知你"** → 把"生死攸关"从被动等待变成提前预告 → 这是收费的重点

**注意：** 竞品 Scrutiny（开源）只有"看盘面的面板"，没有"小白能懂的时间轴 + 微信主动推送"。我们卖的不是 SMART 数据（数据是免费的），卖的是**持续看护服务** —— 这正是"不能卖功能，要卖安心和省事"的最佳载体。

## 三、为什么选买断制而不是年费

### 三个理由

**第一，NAS 用户对"订阅"有心理创伤。**
群晖、威联通这些年把能订阅的都订阅了（Synology C2、各种云服务），用户被反复割过。一提年费，条件反射就是"又一个来收租的"。**买断制反而显得实在。**

**第二，防勒索是"一次性安心"，不是"持续服务"。**
用户心里的账是这样算的：我买的是"出事那天能救回来"的保险，不是"每月享受的服务"。既然是保险，买断更符合直觉。

**第三，成本结构支持买断。**
核心功能完全离线，不占服务器资源；异地副本用用户自己的云存储。**没有任何持续成本，凭什么收年费？** 收年费在良知上站不住，用户一问就露怯。

### 价格锚定话术

不要干巴巴写"¥99"，要给用户参照物：

> **一次数据恢复服务的市场价是 ¥2000+，而它只需要 ¥99，且永久有效。**
>
> **你手机里随便一张照片，花 ¥99 都找不回来。**

这样用户算的不再是"99 块买个软件"，而是"99 块买我全家照片的保险"。

**同一笔钱，参照物不同，感受完全不同。**

### 为什么主推 ¥99 而不是 ¥69

| | ¥69 | ¥99 |
|---|---|---|
| 权限 | v1.x 全部更新 | v1.x + **未来所有大版本** |
| 差价 | — | 多 30 元 |
| 心智 | "够用了" | "一步到位" |

**用户看到差 30 元但更新年限差很多，绝大多数会选 ¥99 —— 这就是价格锚定。而你真正想卖的也是 ¥99。**

## 四、更新策略（版本制）

**用"版本制"代替"年限制"。**

- **¥69 买断** = 永久使用 v1.x + v1.x 所有小版本更新
- **¥99 买断** = v1.x + 未来所有大版本免费升级
- 将来出 v2.0（如勒索行为检测），想要的话再付升级费

### 为什么比"三年更新"更好

| | 三年更新 | 版本制 |
|---|---|---|
| 诚实度 | 要承诺时间 | 不承诺时间 |
| 可持续性 | 三年高强度投入很难（涛哥还有 DeployEasy/HMP/宠物洗护站） | 节奏自控 |
| 用户接受度 | "我买够了吗" | "东西在进步" |

### 更新内容清单（真会做的，不是画饼）

1. **新增系统适配** —— 飞牛/绿联 → 群晖/威联通/TrueNAS/Unraid/OMV
2. **告警渠道扩展** —— 企微/飞书/钉钉群机器人 → Bark/ntfy → Web Push
3. **异地备份目标扩展** —— 更多云盘、NAS 对 NAS、移动硬盘冷备
4. **防勒索能力深化** —— 勒索行为检测、完整性校验、异动审计、一键救援模式
5. **系统升级兼容修复** —— NAS 固件更新后的适配（**这条最值钱**，用户最怕"系统一升级软件就废了"）

### 节奏承诺

**"持续更新，重大功能里程碑发布"** —— 不给"每月更新"这类硬指标。

### 关键设计：License 离线签名

**买断制的致命问题：怎么防止一个 license 装一万台？**

答案分两层：

| 部分 | 授权方式 |
|---|---|
| **核心功能** | **完全不校验**。开源代码，谁都能跑，哪怕没有 license |
| **进阶功能** | **本地 License 文件校验**（离线 RSA/Ed25519 签名，**不联网激活**） |

**为什么必须离线签名：**

1. **永不失效** —— 服务器关了，已买的 license 照样能用（买断制的核心承诺）
2. **零运维成本** —— 不需要激活服务器
3. **一机一码可做但不怕破解** —— license 写入机器指纹，即使被破解也无所谓（核心功能本来就免费）

**核心功能必须做到"拔网线也能救数据"。**
用户装防勒索软件，是为了在"最坏的时候"能救回来；如果这工具本身依赖单点服务器活着，那它保护了什么？

## 五、合规架构：三链路分离

### 为什么不能自建境内收费平台

**ICP 经营许可证管的是"在境内通过互联网向不特定用户持续收费"的平台型业务。** 判断标准不是"服务器在不在境内"，而是主体、用户、经营行为是否在境内。

**把域名放 Cloudflare 并不自动免除合规义务。** 靠技术手段规避行政许可，是有风险的。

### 但你的业务形态天然避开这条线

| | 平台型收费（需 ICP 证） | 卖软件 license（不需要） |
|---|---|---|
| 你提供什么 | 持续在线的服务 | **一次性的软件使用权** |
| 用户买什么 | 平台上的服务 | **一个可以下载/授权的产品** |
| 类比 | 卖 SaaS 订阅 | **卖一套软件，像卖 App** |

**你做的事，本质是"卖软件"，不是"运营互联网信息服务平台"。**

### 三链路分离架构

| 链路 | 方案 | 合规要求 |
|---|---|---|
| **① 收款** | 微信小程序内微信支付（优先）；服务号内支付 | **不需 ICP 经营许可** |
| **② 推送** | 服务器 IP 直连服务号模板消息 API | **不需域名、不需备案**（只需 IP 白名单） |
| **③ 分发** | Docker 镜像（腾讯云 TCR / 阿里云 ACR）+ GitHub/Gitee 开源 | **不需境内网站** |
| **④ 使用** | NAS 本地 Web 界面（局域网访问） | 不对外提供互联网服务 |
| **⑤ 升级** | License 文件离线签名验签 | 不依赖服务器存活 |

**五条里没有一条需要"境内备案域名"，也没有一条构成"ICP 经营许可"监管对象。**

### 备案问题（涛哥的约束）

**现状：域名没备案，用 CF 免费服务。**

| 用途 | 是否要求备案 |
|---|---|
| 服务号挂外部链接（菜单跳转） | ✅ 必须备案 |
| 网页授权（拿 openid）回调域名 | ✅ 必须备案 |
| **服务端调模板消息接口推送** | ❌ **不要求，只要 IP 白名单** |
| 微信支付回调 | ⚠️ 实际要求可访问，备案域名更稳 |

**结论：真正必须备案的只有"网页授权 + 内嵌网页"这一小块，而它可以用「6 位绑定码」和「小程序」完全替代。**

### 必须避开的红线

- ❌ 不要自建境内域名、面向公众注册、按年订阅收服务费的云平台
- ❌ 不要做明显的规避动作（境外主体、不留联系方式）
- ✅ 企业客户要发票 → 接第一个企业单时再注册个体户

### 免责说明

以上为基于公开规则的判断，**非法律意见**。体量小时不必焦虑；若年收入几十万以上，花几千块咨询专业财税/法律。

## 六、为什么不做 OEM 授权

**曾考虑：把防勒索能力打包卖给飞牛/绿联，收一次性授权费 + 每台分成。**

**结论：不做。** 三层硬障碍：

1. **没有对接渠道** —— 个人开发者敲不开企业采购的门
2. **对方自己会做** —— 快照功能他们已经有了，防勒索是他们的产品必修课，凭什么外包？
3. **个人主体过不了采购** —— 要资质、发票、售后 SLA、法务主体；且从接触到回款一年起步，**与"恢复现金流"背道而驰**

**正确的替代路径：不做 OEM，做"面向这些品牌用户的"外围工具。** 直接服务用户，不需要任何公司点头。

## 七、三条变现线（同时挂着）

```
① 买断制          ¥69 / ¥99          主力收入
② 代部署服务      ¥100-300/次        小白不会装，用户不抵触服务收费
③ 企业版          按台议价            撑价格体系 + 后期利润空间
```

**为什么要三条一起挂：**

用户分三种人 —— 想要便宜的、讨厌年费要买断的、不想动手要人代装的。**三种人都有对应入口，转化率才高。**

### 企业版的作用（现在不用花精力）

- 撑住价格体系（有 ¥199/台 在那，¥99 买断显得白菜价）
- 真有客户找上门时，有现成报价单
- **个人用户赚吆喝，企业用户赚钱**

## 八、获客与传播

### 一个反直觉的结论

**"没备案"这件事，限制了网页链接类的传播（H5 落地页、服务号外链）。**

所以引流要**避开网页链接，回到内容渠道**：

- 飞牛官方社区
- 绿联论坛 / QQ 群 / 微信群
- 什么值得买
- B 站

### 发帖策略（关键）

**别写"我做了个快照工具"（没人点）。要写：**

> **《飞牛用户注意：你的快照可能救不了你 —— 我做了个工具补上这个洞》**

**内容结构：**
1. 指出问题（系统自带的快照，管理员能删 —— 引厂商文档为证）
2. 给出方案（我做了个东西，把快照锁住、能捞单个文件、出事前会告警）
3. 一行命令安装

**这种"指出问题 + 给解决方案"的帖子，转化率远高于"我做了个工具请支持"。**

### 安装必须简单到极致

小白看到"要 SSH、要改配置"就走了。目标是：

```bash
docker compose up -d
```

**复制粘贴就能跑。这一步的完成率，直接决定用户量。**

### 口碑飞轮

```
用户装了（为了省空间/找文件）
    ↓
顺手开了快照保护
    ↓
某天中招 → 一键回滚救回来
    ↓
用户震惊 → 主动发帖/发群
    ↓
新用户（获客成本 = 0）
```

**用户的真实路径不是"我要防勒索所以装软件"，而是"我清了垃圾顺便开了个保护，没想到真救了命"。**

## 十、诚实的定位建议

**这个项目离"赚钱"还有距离。**

它可能是个好工具，但好工具不等于好生意。基于涛哥当前"需要恢复现金流"的处境，诚实的排序是：

1. **先做能快速变现的事** —— 已有能力（NAS 部署、群晖威联通迁移、影视库搭建、小程序、IoT）接单或代部署，这是几天内能收到钱的
2. **本项目当"名片"做** —— 开源、免费、发到社区。不一定直接赚钱，但能让别人看到技术能力，**接单时它是作品集**
3. **如果它意外火了，再考虑商业化** —— 火了之后是用户推着你走，不是你去求渠道

**别把宝押在一个需要渠道、需要时间、需要公司资质的模式上。**
