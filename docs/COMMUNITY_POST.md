## 正文

### 先说一个很多人不知道的事实

绝大多数 NAS 的快照，包括飞牛、绿联、群晖、威联通，**都是"管理员能删"的快照**。

绿联官方文档自己写过一句很直白的话：

> "Locked snapshots also remain manageable by an administrator, so they are not immutable recovery copies."
> （锁定快照管理员照样能管，所以不是不可变的恢复副本）

威联通、群晖同理。**问题在哪？** 现代勒索软件的攻击链是：
入侵 → 横向移动 → **找到备份/快照的管理权限** → 把快照删干净 → 最后才加密你的数据。

换句话说：**你以为的"最后防线"，在攻击者眼里是第一目标。**

### 我做了个什么

一个专门给 NAS 数据上锁的工具，叫 **NAS Safe**（开源，MIT）：

- **跨品牌统一时间轴**：飞牛 / 裸 Linux / TrueNAS / OMV / Unraid / 威联通 / 群晖，一个界面管
- **快照锁定 + 篡改检测**：你锁定的快照一旦被删 / 被解锁，立刻顶栏红黄告警（前端每 30s 巡检），不再是"静默被删"
- **单文件取回**：不一定要整卷回滚，能进快照里勾选某个文件直接捞出来（系统自带基本没有好用的单文件取回）
- **装完默认开启**：不用进面板研究参数，降低"用户根本没开快照"的概率

### 为什么要做这个，而不是用系统自带的

| 系统自带快照 | NAS Safe |
|---|---|
| 只有整卷/文件夹回滚 | 支持单文件取回 |
| 管理员能删（不免疫勒索） | 独立权限 + 篡改告警 |
| 只能管本机 | 多台设备同一时间轴 |
| 默认不开、要自己配 | 装完即默认开启 |

### 免费还是收费

- **免费版**：核心引擎 + 时间轴 UI + 单文件取回 + 一键回滚，**全部免费，且完全离线可用**（断网也能救数据）
- **进阶版**：自动策略 + 快照锁定 + 篡改告警 + 异地副本 + 多设备看板（一次性买断，¥69 / ¥99 起）

开源地址：https://github.com/lw76p/nas-safe
